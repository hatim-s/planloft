# Planloft 1.0.1

Status: prepared, not published.

## What changes

Every compiled document offers reading-width and full-width controls. Markdown and
MDX retain their shared article layout. Authored HTML now gets the controls without
requiring `.planloft-plan > article`, using the body as its width container instead.
Full-width mode also removes width caps on direct `main` and `article` children.

The reader's selection persists across documents. Reading width defaults to 44rem
and respects `--planloft-measure`. Print output removes the reading-width cap.

Recompile existing HTML artifacts to receive the change. Authored HTML structure,
scripts, and content remain intact. Custom fixed-width CSS can still constrain
nested content.

## Publish

From a clean, synchronized `main` checkout, run:

```sh
bun run release 1.0.1
```

The release command validates the package, publishes it to npm, and pushes `v1.0.1`.
